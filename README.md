## Features

- Yarn Count Converter
- Fabric GSM Calculator
- Fabric Shrinkage Calculator
- Dyeing and Chemical Calculator
- Production Efficiency Calculator
- Moisture Regain and Moisture Content

## Technologies

- Python
- Streamlit

## Run Locally

Install Python and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deployment

1. Upload `app.py`, `requirements.txt`, and `README.md` to GitHub.
2. Open https://share.streamlit.io/
3. Sign in with GitHub.
4. Select this repository.
5. Set the main file path to `app.py`.
6. Click Deploy.
